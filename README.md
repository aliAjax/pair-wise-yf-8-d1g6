# 胶片分镜条酸损隔离台

一个纯前端本地应用，用来整理纸质放映胶片片段、记录醋酸片基酸损检测数据、按规则自动隔离酸损片、管理通风复检与恢复流程，并导出试映清单和处置留档。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据保存在浏览器 localStorage（键 `zfl17-film-acid-desk`），旧版核对台数据（`zfl17-film-strip-desk`）首次打开时自动迁移。

## 酸损判定规则

每段胶片录入三项检测数据：**试纸等级、收缩率、湿度**。

- 试纸 **A 正常、B 观察、C/D 隔离**。
- 湿度 **超过 65%** 至少判为 B（观察）。
- 湿度 **超过 75%** 直接判为 C（隔离）。
- 湿度只上调、不下调试纸等级；最终以每次录入的最新一条检测记录为准。收缩率仅记录与导出，不参与判定。

## 隔离与恢复

- 判定为 C/D（或湿度 >75%）的片段**自动退出试映顺序**，进入下方“酸损隔离台”。
- 隔离段在隔离台进行**通风复检**（再次录入试纸等级、收缩率、湿度）。
- 恢复试映须同时满足：最新等级降到 **A/B**、湿度 **≤65%**，并由**另一名库员**（不得与复检人为同一人）确认。
- 未达标时只能继续复检，不能恢复。

## 统计与留档

- 顶部统计与导出文件只反映每段的**最新等级**；试映总时长不含隔离段。
- 录入、检测更新、通风复检、隔离、恢复放映等处置动作均自动留档（含时间、操作人、详情），页面显示最新 4 条，导出包含完整记录。

## 文件结构

- `archive.js`：存档层（领域逻辑）——等级判定、隔离/恢复流程、处置留档、localStorage 读写。
- `app.js`：页面层——DOM 渲染、表单与拖拽事件，不直接操作存储。
- `index.html` / `styles.css`：结构与样式。

## 测试

- `node test-archive.js`：存档层规则与隔离/恢复流程测试。
- `node smoke-test.js`：页面层渲染、事件委托与导出的冒烟测试（轻量 DOM 桩，无需浏览器）。
