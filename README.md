# 胶片酸损隔离台

一个纯前端本地应用，在原有分镜条核对、拖拽排序、筛选导出的基础上，加入醋酸综合征（酸损）防控流程。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 检测与分级

- 每段同录三项检测数据：**试纸等级（A/B/C/D）、收缩率（%）、湿度（%）**，并记录检测库员。
- 等级规则：
  - **A 正常**：可正常试映。
  - **B 观察**：留通风观察，列入观察名单。
  - **C / D 隔离**：退出试映顺序，进入酸损隔离区。
- 湿度修正（与试纸等级取更严一档）：
  - 湿度 **>65%**：至少 B（观察）。
  - 湿度 **>75%**：直接 C（隔离）。
- 同一分段可多次复检，**统计、标签和导出均取最新一次检测算出的综合等级**。

## 隔离与恢复

- 判定 C/D 的片段自动退出"试映顺序"，不可拖拽、不会混映，统一列在"酸损隔离区"。
- 隔离段点击"通风复检"：
  - 试纸等级须降到 **B 或以下（A/B）**；
  - 湿度须 **≤65%**；
  - 须由**另一名库员**确认（复检人与确认人不得同名）。
- 三个条件同时满足才恢复试映；任一不满足弹窗拒绝，继续隔离。

## 留档与存储分离

- 隔离、复检、恢复均写入"处置留档"，记录时间、编号、等级变化、原因、复检/确认库员。
- 页面清单（片段、顺序、检测历史）与处置留档分别使用独立的 localStorage 键维护，清空留档不影响页面数据。
- "导出清单"输出最新等级的试映顺序、隔离区与观察名单；"导出留档"单独导出全部处置记录。

## 本地冒烟测试

可选（需安装一次 `jsdom`）：

```bash
npm install --no-save jsdom
node smoke-test.js
```

覆盖隔离退出顺序、湿度阈值升级、复检三条件（降到 B、湿度 ≤65%、另一名库员确认）、恢复流程以及页面/留档存储分离。
